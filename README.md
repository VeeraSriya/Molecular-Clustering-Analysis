# Molecular Clustering Analysis

## Overview
This project groups molecules automatically using unsupervised machine learning.

## Objective
Identify chemically similar molecules based on molecular descriptors.

## Descriptors Used
- Molecular Weight (MW)
- TPSA
- Hydrogen Bond Donors (HBD)
- Hydrogen Bond Acceptors (HBA)
- LogP

## Machine Learning Method
- K-Means Clustering

## Visualization
- Principal Component Analysis (PCA)

## Workflow
Molecules → Descriptors → K-Means Clustering → PCA Visualization

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Learning Outcome
Understanding unsupervised learning, clustering, PCA, and molecular data analysis.
